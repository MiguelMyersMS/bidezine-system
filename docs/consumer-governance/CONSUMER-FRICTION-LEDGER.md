# Consumer Friction Ledger

The evidence-backed record of every defect surfaced by the production test (`docs/consumer-governance/
COMMUNICATION-PROTOCOL.md` + `scratchpad/DS-PRODUCTION-TEST-PLAN.md`). One row per defect. This ledger IS the
deliverable of the test — a prioritized, gated backlog of DS changes, not anecdotes.

**A row closes to `FIXED` only when its fix ships a NAMED EXECUTABLE regression gate** (an export assert in
`check:umd-fresh`, a `scripts/audit-umd-surface.js` snapshot, or a `--*-contract` play story in
`npm run health`). A prose-only fix (spec/README/prompt text) stays `OPEN (doc-debt)` and does NOT count
toward convergence.

Defect classes (from the attribution tree): `consumption` (bundle/package) · `docs` · `composition`
(props/slots/layout) · `behavior` · `consumer-host` (zero DS change) · `non-defect` (valid config).
