## Context

The design system needs a component playground for interactive testing, documentation, and visual regression. Storybook is the industry-standard tool. Version 10 introduced CSF factories, bundled essential addons into core, and improved performance with the Vite builder.

## Decision

Use Storybook 10 with `@storybook/react-vite` framework:

- Essential addons (controls, actions, docs) bundled in core — no separate `@storybook/addon-essentials`
- `@storybook/addon-a11y` added separately for accessibility panel
- `storybook/test` replaces `@storybook/test` for play functions and interaction testing
- Stories use CSF3 format in `src/**/*.stories.tsx`
- `defineMain` / `definePreview` API for configuration

Visual regression uses Playwright (self-hosted) rather than Chromatic (SaaS):

- Baseline screenshots stored in repo
- Light and dark theme variants captured
- Playwright runs against the static Storybook build

## Consequences

- All gallery components have stories with autodocs
- Theme decorator wraps all stories in `ThemeContext` with toolbar toggle
- Interaction tests use `play` functions with `within`, `userEvent`, `expect`
- Visual regression baselines generated by `npx playwright test --update-snapshots`
