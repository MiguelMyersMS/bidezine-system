**Conventions (so this stays the single source):**
- **Record:** add a `- [ ]` line under `## Open` (committed when you say "record a follow-up: …").
- **Close:** check it off (`- [x] … (done <sha> <date>)`) and move it to `## Done (recent)` in the same commit.
- **Prune:** keep `## Done (recent)` to entries since the last push; older done items live in git history.

> **This file vs `MEMORY.md`:** this is the in-repo, branch-traveling, team-visible **backlog** (actions).
> `MEMORY.md` is the local cross-session **pointer index** (orientation). Actions go here; pointers go there.
